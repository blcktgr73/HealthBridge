## Walking skeleton

Release 1의 첫 번째 세로 슬라이스는 다음입니다.

`Health Connect 권한 확인 → 최근 7일 걸음 집계 → health.v1 생성 → webhook POST → 수신 성공 표시`

이 슬라이스가 실제 기기와 Spike endpoint에서 동작하면 나머지 데이터 타입과 복구 기능을 세로로 확장합니다.

## 우선순위 규칙

- 위에서 아래로 사용자 가치가 높은 흐름을 먼저 구현합니다.
- 같은 행의 기능은 가능한 한 하나의 동작 가능한 세로 슬라이스로 검증합니다.
- 자동화·심박수·체중은 수동 동기화와 데이터 계약이 안정된 뒤 추가합니다.
