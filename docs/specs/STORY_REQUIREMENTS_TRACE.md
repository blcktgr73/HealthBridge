## 현재 시험과 미결정

- 첫 시험은 단일 agent + 합성 7일 걸음이다. 실제 agent 확인은 메모리 receiver 시험만으로 입증되지 않는다. [#2](https://github.com/blcktgr73/HealthBridge/issues/2), [#12](https://github.com/blcktgr73/HealthBridge/issues/12).
- 현재 합성 `daily_summary.steps`는 최근 7일 합계다. 실제 일별 payload 계약은 미결정이다. [#8 결정](https://github.com/blcktgr73/HealthBridge/issues/8#issuecomment-7216026675).
- [REQ-009/TASK-011·012](../requirements/REQ-009-receiving-transmission-decision.md), [REQ-010/TASK-013·014](../requirements/REQ-010-retention-user-experience-decision.md)는 제품 정책 결정이며, 이 문서의 후보 기준을 승인하거나 실제 데이터 접근을 허용하지 않는다.
- 스토리 맵의 설치·실행은 기존 합성 화면 #4/PR #5의 기반이지만 실제 기기 릴리스 동작을 입증하지 않는다. 심박수 배치 및 데이터 범위, 사용자 가치와 성공 기준은 #2에서 결정한다.
